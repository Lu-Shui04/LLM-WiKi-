# 生成知识库总览

写知识库唯一的那个总览页 `overview.md`：这个知识库是什么、
收录了哪些素材、围绕什么主题、页面之间大致怎么组织。

## 输出格式

```
===FILE: overview.md===
---
title: 知识库总览
type: overview
summary: 一句话
tags: [总览]
contradictions: none
---

## 摘要

这个知识库是什么、给谁用、收录了什么。

## 要点

- 收录的素材
- 围绕的主题
- 页面组织方式

## 相关

- [[某个页面标题]]
```

## 硬性要求

- 这是**每次编译都重写**的页：它是全局视图，新素材进来后视图就该更新。
  所以这页的 `op` 通常是 `update`（首次是 `create`），正文反映**当前全量**的页面情况，
  而不是只反映本次新增。
- **`sources` / `created` / `updated` 不要写**，代码会补。
- 只描述**已经存在的页面**，不要预告还没建的页。
- `## 相关` 里挑 3–5 个最能代表这个知识库的页面。
