# 生成实体页与概念页

按规划清单，生成本次要写入的**实体页**和**概念页**。一个页面一段，各自以
`===FILE: <目录>/<文件名>.md===` 开头。

## 输出格式

```
===FILE: concepts/意图路由.md===
---
title: 意图路由
type: concept
summary: 一句话
tags: [速购客服, 架构]
contradictions: none
---

## 摘要

两三句话。

## 要点

- 一条一个独立事实

## 细节

### 来自《我的简历》

（这份来源提供的展开内容）

## 相关

- [[订单Agent]]
```

## 硬性要求

- **只输出清单里列出的页面，不多不少；每个页面只输出一次。**
- **`## 细节` 要写足。** 原文里的数字（chunkSize、Top-K、温度、维度）、
  流程步骤、取舍理由、结论，都应该落在这一节——
  这些正是摘要页装不下、才需要单独开页的东西。一页 300–1200 字是正常的。
- **`sources` / `created` / `updated` 都不要写**，代码会补。
  你只写 `title` / `type` / `summary` / `tags` / `contradictions`。
- 目录必须和类型对上：`entity` → `entities/`，`concept` → `concepts/`，
  `comparison` → `comparisons/`。
- **`## 细节` 下按来源分 `### 来自《文件名》` 小节。**
  本次只涉及一个来源就只写一个小节。
- **更新已有页面时是整页重写，不是追加、不是打补丁。**
  通读该页现有全文，结合本次来源，产出完整的新版本。
  已有的「来自别的来源」的小节要原样保留，不要因为重写就丢掉。
- **页面长度由内容决定，不由编译次数决定。** 同一份文档编译十次，
  页面不该膨胀十倍。
- **没有新事实就整页 `skip`，一个字都不写。** 不要为了改写而改写。

## 交叉引用

- 语法 `[[中文标题]]`，不带目录前缀。
- 目标**只能从已知页面清单里选**（含本次将创建的页面）。
- 确实没有可引用的对象时，`## 相关` 整节省略。

## 矛盾

只有确实发现两处不相容的陈述时才写 `## 矛盾` 小节，
并严格按 SCHEMA.md 第六节的格式给出 A、B 两处原文摘录 + 不相容理由。
**没有矛盾就整节省略，不要写「无」。** 同时把 frontmatter 的 `contradictions` 置为 `open`。
